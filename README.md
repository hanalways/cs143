## Contributing 
This is a gradle project, primarily built in IntelliJ. To get started clone the repo and run `./gradlew run`.

To test all files run `./gradlew test` or to test a single file run `./gradlew test --tests '*TestSuiteNameHere'`

Project is structured:
* introduce new folder under /main/java/edu/hanalways/cs143 per week or new unit of material.
* /main/test/java/edu/hanalways/cs143 to add relevant unit tests.
* /resources to dump all files that are related to the class and/or assignments.
